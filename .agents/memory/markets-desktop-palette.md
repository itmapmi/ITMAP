---
name: Markets desktop palette parity
description: Color-system rule for mobile Markets surfaces.
---

Mobile Markets screens must use the desktop semantic palette for backgrounds, text, cards, borders, inputs, buttons, links, active sections, dialogs, and disabled states.

**Why:** The user rejected a separate cream/teal/coral mobile palette and wants the desktop and mobile Markets experience to feel like the same product.

**How to apply:** Use desktop white/light-neutral surfaces, near-black text and secondary actions, blue primary actions, and pale-blue active highlights. Preserve vendor-series and support/severity colors only when they encode data.
