---
name: Cross-device typography consistency
description: Typography rule shared by desktop and all mobile product surfaces.
---

Mobile product designs must match the desktop typography system: Montserrat for body and headings, Menlo for technical/data text, and the literal ITMAP wordmark in Montserrat 600 at 22px with 0.18em tracking.

**Why:** The user identified inconsistent mobile fonts and wants one recognizable visual identity across desktop and mobile.

**How to apply:** Apply this rule to Markets, CVE Intelligence, RFP Builder, and future mobile sections. Preserve product-specific layout and color treatments; only technical/data labels should use Menlo.
