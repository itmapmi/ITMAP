---
name: RFP Builder mobile boundary
description: Visual and product constraints for the buyer RFP Builder mobile redesign.
---

The buyer RFP Builder uses a black/dark workspace across Projects and its exact six-step wizard: Interview, Requirements, Preview, Shortlist, Outreach, and Export.

**Why:** The user wants the mobile redesign to match the existing desktop's black treatment and follow the same strict feature-parity process used for Security Intelligence.

**How to apply:** Preserve project limits and LLM-key gating, mobile progress and Back/Next behavior, readiness-gated generation, stored requirements, generated sections, shortlist fields, outreach tracking/upload limits, and PDF/DOCX/XLSX availability. Do not add steps, analysis, recommendations, export history, or unsupported workflows.
