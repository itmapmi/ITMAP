# Project Overview

ITMAP AI Market Builder application. Provides an admin wizard for building technology market research reports across 9 stages (vendor list, scoring, commentary, product features, ecosystem features, etc.) and publishing them as ITMAP market pages.

## User Preferences

- **Market Builder Excel templates must match the admin market export format.** The downloaded import template for any stage should contain the same three tabs used when exporting/importing a market from the admin panel: **Vendor Evaluation**, **Product Evaluation**, and **ISV Ecosystem**. Backward compatibility with the old single-sheet `Template` format is preserved for existing imports.
