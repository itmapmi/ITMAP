Design a completely separate mobile user interface for the ITMAP market research platform.
The desktop version already works well — this mobile design must not simply resize or adapt the desktop version. Instead, it should use a distinct mobile layout system optimized for small screens and touch interactions.

Goal

When users log in from a phone, the app should load a native-style mobile experience, not a shrunk or responsive desktop version.

Design Requirements

Create unique React components and CSS layouts exclusively for mobile (not shared with desktop views).

Detect mobile users on login and redirect to the mobile interface (e.g., /mobile-dashboard, /mobile-report-view, /mobile-chart etc.).

Use bottom navigation tabs instead of top menus.

Replace multi-column layouts with single-column cards for readability.

Optimize charts (like quadrant visualizations) to render full width and stack vertically.

Ensure touch-friendly interactions — large buttons, clear spacing, and swipe-friendly lists.

Prioritize fast load and minimal scrolling; collapse secondary info into expandable sections.

Maintain the same data and logic backend — only change the presentation layer.

Screen Requirements

Login / Authentication Screen

Clean, centered form with large fields and ITMAP logo.

Option for “Sign in” or “Get Started” with full-width buttons.

Home Dashboard (Mobile)

Quick access cards: Reports, Vendor Eval, Product Eval, Ecosystem, News.

Include icons and short titles, not large blocks of text.

Report View

Scrollable vertical design with collapsible sections (Summary, Chart, Vendors, Methodology).

Quadrant chart (like the High-End General Purpose Storage Arrays map) should be centered, zoomable, and scrollable on mobile.

Navigation

Bottom navigation bar with 4–5 main icons: Home, Reports, Vendors, News, Profile.

Floating “+ Report” button for creating or viewing reports.

Vendor / Product Detail Pages

Use vertically stacked tabs (Overview, Pros & Cons, Scores, News).

Allow swipe navigation between sections.

Profile / Account

Compact profile screen with settings, dark mode, and logout.

Design Notes

The UI must feel native-app-like (clean, card-based, gesture-friendly).

Do not shrink or compress desktop tables; use stacked layouts or summary views.

Use adaptive typography and spacing for mobile readability.

Ensure smooth performance even on low-end mobile browsers.

Deliverables

Separate mobile routes, components, and CSS modules.

Fully responsive but with mobile-only logic and styling overrides.

Keep the same APIs and data connections as the desktop version.

The final product should make the ITMAP mobile experience feel purpose-built, not like a “scaled-down” desktop site.
