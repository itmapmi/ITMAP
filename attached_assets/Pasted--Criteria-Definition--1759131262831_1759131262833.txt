| **Criteria**                                           | **Definition**                                                                                                                                                                |
| ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Predictive analytics for failure detection**         | Uses AI/ML to analyze telemetry data from storage arrays to anticipate hardware or software failures before they occur, reducing downtime and enabling proactive maintenance. |
| **Predictive analytics for remediation**               | Goes beyond detection by recommending or executing corrective actions in advance, minimizing disruption through automated repair steps or guided workflows.                   |
| **Automated anomaly detection**                        | Continuously monitors system behavior to identify deviations from normal patterns, helping uncover hidden issues in performance, utilization, or data access.                 |
| **Automated root cause analysis**                      | AI-driven correlation of logs, metrics, and events to quickly pinpoint the underlying cause of an issue, reducing mean time to resolution (MTTR).                             |
| **AI-driven workload placement**                       | Dynamically assigns workloads to the most suitable resources in the array based on performance, latency, and capacity requirements.                                           |
| **AI-driven workload optimization**                    | Continuously tunes system resources to improve workload performance and efficiency, balancing throughput, IOPS, and latency.                                                  |
| **Intelligent tiering**                                | Automatically moves data between storage tiers (e.g., NVMe, SSD, HDD) based on usage frequency and performance needs, optimizing cost and performance.                        |
| **Intelligent data migration**                         | Simplifies and accelerates data movement across storage arrays or environments using AI to minimize disruption and ensure efficiency.                                         |
| **Adaptive performance tuning**                        | AI algorithms automatically adjust system parameters in real time to maintain optimal performance under varying workloads.                                                    |
| **Automated capacity forecasting**                     | Uses trend analysis and predictive models to forecast future storage needs, helping avoid unplanned capacity shortfalls.                                                      |
| **Automated capacity planning**                        | Provides AI-driven recommendations for scaling or reallocating resources, aligning with business growth and workload requirements.                                            |
| **Self-healing mechanisms**                            | Enables the system to automatically detect, isolate, and remediate faults without human intervention, ensuring resilience and availability.                                   |
| **AI/ML-based anomaly detection for security threats** | Identifies unusual patterns in data access, user behavior, or system activity that could indicate ransomware, intrusions, or insider threats.                                 |
| **Autonomous policy creation based on usage patterns** | Leverages AI to create and update operational policies (e.g., QoS, tiering, snapshots) dynamically, aligning with observed user and workload behavior.                        |
